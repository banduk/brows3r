# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

The canonical text lives at the URL above; we don't inline a copy here
because the upstream version is the source of truth and gets occasional
revisions.

## Reporting

To report a concern, contact the maintainers via the same channel as
security reports: see [SECURITY.md](SECURITY.md) for the address. We
respond within 72 hours and handle reports in confidence.

## Scope

The Covenant applies to all project spaces: this repository, the issue
tracker, the documentation site, any chat channels we adopt later, and
project-related interactions at events.
