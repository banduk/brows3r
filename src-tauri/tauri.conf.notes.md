# tauri.conf.json — notes

## `plugins.updater.pubkey` placeholder

The `pubkey` value in `tauri.conf.json` is a placeholder string.

Before shipping a release, replace it with the real Ed25519 public key
generated by `tauri signer generate`. The full procedure is documented in
`docs/contributing/release.md` (Section 1).

## `plugins.updater.endpoints` placeholder

The endpoint `https://updates.brows3r.dev/{{target}}/{{current_version}}`
is the intended production URL. It is not live in v1. The release workflow
(tasks 63-65) must deploy an update server or static JSON feed at this address
before auto-update can function end-to-end.

## `plugins.updater.dialog`

Set to `false` because the in-app `UpdaterPrompt` component handles all user
interaction. The Tauri built-in system dialog is intentionally disabled.

## `bundle.icon` — placeholder icons

v1 uses placeholder icons generated by the Tauri scaffold (stored in
`src-tauri/icons/`). Replace with a branded icon set before public release.
All required sizes for macOS, Windows, and Linux are listed in the `icon`
array. See the Tauri documentation for icon format requirements per platform.
